No "show more": every branch on this box is a card. 30 branches = 30 cards and the agents get pushed far down. That scroll IS the nudge.

"Workspace as it is" replaces the blank field, and says which branch that really is. That branch never gets its own card below.

"has folder" = the branch is open for editing in its own folder (git calls it a worktree). Still one card: the folder belongs to it.

"Leftover folders" = folders whose branch is gone. Only the files remain on disk. ✕ removes the folder.

"odd name" = a branch on this box whose name starts with the name of any online copy (origin/, upstream/, ...), so it looks like an online one.

Every tap re-checks first ("checking..."). Nothing to lose → straight to C. Something to lose → confirm inside the card.

Greyed ✕: tap shows one line why.

"has folder" card: the delete removes the folder first, then the branch. If the folder can't be removed, the branch is left alone.

If the folder has edits that were never saved, the confirm says "can't be undone", and C shows no Undo.

Happens when an agent switched the workspace to another branch and left it there.

The default branch never gets ✕, even when it has no folder.

"Switch back to main" works only when no live session uses the workspace and nothing there is unsaved. Otherwise it's greyed, with one line why.

Default branch: asked of the online copy on the refresh that already runs after the dialog opens, then remembered on this box. Until it's known: guess main, else master, and neither gets ✕.

Decision table: every branch case

Speed, measured on a box with 11 branches and 4 folders. Instant = under 0.01 s, read from this box, ready when the dialog opens. Soon = 0.07-0.2 s, the tag fills in just after the card appears. Background = asks the online copy, about 3 s, never blocks the dialog, gives up after 20 s.
