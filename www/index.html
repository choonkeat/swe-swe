Install one of these first

swe-swe needs either Docker, or git plus a coding agent already on the machine. There is no third way.

Easiest: install Docker, then come back and pick the first option.

Or: install git and one of claude, gemini, codex, goose, aider, opencode, pi — then pick the second option.

Pick one. This applies whichever way you answered above.

Your own laptop, or a machine on your network. Each session gets its own port for the app preview, and they all just work.
That is: anything.<the machine's hostname> reaches it, whatever you put in front of the dot. Running it locally, lvh.me already behaves this way.
how do I check?

In a browser on the machine you will actually be using, open anything.<the machine's hostname> — literally the word "anything", or any word you like. If it reaches this machine, pick this one.

swe-swe serves every pane on that one port, each on its own subdomain. No tunnel, nothing to paste, no steps after boot. Plain addresses; for a padlock, whatever handles the encryption in front needs a certificate covering every subdomain.
You open it at a single address, like https://my-box.example.com, and nothing else on that machine opens. Usual for a hosting service, a rented server with one way in, or a work network that blocks the rest. Nothing to set up.
how do I check?

If all you were handed is one address to open, pick this one. To be sure, add :8080 to the end of that address (after the name, before any /) and try to open it in the browser you will actually use. If it does not open, pick this one.

Works: the terminal, Agent Chat, Files, the app preview and the live Agent View, all served from the one address you opened.
Not available: the separate web address for your app that other people can open without logging in. That is a second address by nature.
Also: the per-session ports the other answers rely on are neither forwarded nor opened, so there is nothing extra listening on this machine and no pane waits to find that out.
One caveat: every pane shares the page's address, so a web page opened in the Files pane can reach into the page around it.

And on the different machine, the one with the browser

Run this there, not on the machine above. Pick any shared secret you like, as long as both machines use the same one.

Then, once per boot, in your browser

About 30 seconds. None of this is a command, so there is nothing to copy.

  1. Open the address your host gives you, and log in with your password.
  2. Gear icon, then Settings. In the "Tunnel secrets" box, paste your tunnel lines. Apply.
  3. The dot on the gear turns amber while it connects, then green. The link appears under "Tunnel secrets" in Settings, with a Copy button. Open that link. Every pane works there, and it is the same link every boot.
